# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | Yes                |
| < 1.0   | No (pre-release)   |

## Reporting a Vulnerability

**Do not open a public GitHub issue for a security problem.**

Email the details to **info@cyberlegends.org** with the subject
`[subdomain-takeover-checker] Security report`. Include:

- What the issue is and what it affects
- Steps to reproduce it, if you have them
- The version or commit you tested against

Do not include a real vulnerable domain in the report unless it is
your own. If the issue is a subdomain takeover you found on someone
else's domain, report it to that domain's owner through their own
security contact first, and give them time to fix it before
disclosing anything.
